# SIM JUYONG | ゲーム制作ポートフォリオ

東海大学 情報メディア学科、2027年卒業予定。ゲームプログラマー志望の制作ポートフォリオです。

## 掲載作品

- **VR寿司弾丸**：プレイ動画、作品説明書、担当機能、注文システムの構成と開発中に対応した問題
- **手の震え体験ゲーム**：制作中の卒業研究。ゲーム画面、実物デバイスの動作デモ、夏休みの開発記録とグラフィック変更前後の比較

## 構成・更新

ビルド不要の静的サイトです。文章・レイアウトは `index.html` で編集します。
画像・動画・PDFは同じディレクトリに配置しています。変更前後の比較画像は、進捗発表資料の動画から取り出した静止画をHTML内に埋め込んでいます。

GitHub Pagesの公開元は `main` ブランチの `/ (root)` です。

本WebページのデザインにはAIの支援を利用しています。各ゲームの担当範囲はページ内に記載しています。
