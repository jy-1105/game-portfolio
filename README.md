# SIM JUYONG | Game Programmer Portfolio

東海大学 情報メディア学科、2027年卒業予定。ゲームプログラマー志望の制作ポートフォリオです。

## 掲載作品

- **VR寿司弾丸**：プレイ動画、作品説明書、担当機能、実装上の課題と改善
- **手の震え体験ゲーム**：開発中の卒業研究。ゲーム画面、カップ型デバイスのデモ、実装済み機能と今後の課題
- **FLY_PANCAKE**：作品概要と担当機能

## 構成

`index.html` にHTML、CSS、JavaScriptをまとめています。外部パッケージやビルド工程は不要です。画像・動画・PDFは同じディレクトリに配置しています。

GitHub Pagesの公開元は `main` ブランチの `/ (root)` です。

## 更新

文章は `index.html` 内で編集できます。公開用GitHubリンクや連絡先は末尾の `portfolioConfig` で設定します。空欄の項目は表示されません。

本WebページのデザインにはAIの支援を利用しています。各ゲームの担当範囲はページ内に記載しています。
