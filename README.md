# SIM JUYONG | ゲーム制作ポートフォリオ

東海大学 情報メディア学科、2027年卒業予定。ゲームプログラマー志望の制作ポートフォリオです。

## 掲載作品

- **VR寿司弾丸**：プレイ動画、作品説明書、担当機能、注文システムの構成と開発中に対応した問題
- **手の震え体験ゲーム**：制作中の卒業研究。全体プレイ動画、音声付きのデバイス振動デモ、3つのギミック

## ソースコード

[VR寿司弾丸の主要ソースコード（7ファイル）](source/vr-sushi/README.md)を公開しています。各ファイルの役割と、この公開範囲に含まれないものを記載しています。

## 構成・更新

ビルド不要の静的サイトです。文章・レイアウトは `index.html` で編集します。
画像・動画・PDFは同じディレクトリに配置しています。

ギミック動画は進捗発表資料のGIF原本から変換しています。音声付きのデバイス動画と全体プレイ動画は、追加提出された動画を使用しています。中間発表資料をもとに操作方法・システム構成を補足しました。

GitHub Pagesの公開元は `main` ブランチの `/ (root)` です。

本WebページのデザインにはAIの支援を利用しています。各ゲームの担当範囲はページ内に記載しています。
