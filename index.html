VR寿司弾丸

客の注文に合わせて寿司を作り、投げて届けるVRゲームです。私はゲームプレイ全般のプログラムを担当しました。

Unity / C# / SteamVR / NavMesh

プレイ動画を見る ↑作品説明書（PDF）↗実行データをダウンロード（ZIP）↓

Windows用 · 約148MB · SteamVR・対応VR機器が必要です。
ZIPをすべて展開し、フォルダー内の New Sushi Master.exe を起動してください。

担当した機能

  • 寿司の生成・つかみ・投擲
  • 注文アイコンと残り時間の頭上UI
  • 客の生成・空席判定・移動・着席
  • 注文の正誤判定とスコア管理
  • ランク表示とプレイ振り返り演出

実装例：注文システム

注文の処理と、頭上UIの更新を分ける

注文の生成、タイマー、UI更新、正誤判定が1つのクラスに集中していました。UIの変更と注文処理を分けて扱えるよう、データ・進行・表示を分ける構成に整理しました。

SushiOrderData
注文データを保持する
CustomerOrderWithTimer
注文の進行と、受け取った寿司の正誤を判定する
CustomerOrderView
注文アイコンや残り時間を表示する

寿司を受け取る入口を一本化し、正誤判定を注文管理側に集約しました。寿司の種類の比較にはenumを使い、既存の投擲処理との受け渡し部分で変換しています。

ほかに対応したこと：座席管理・リトライ処理

移動中に客が消えたときの座席管理

客の生成時に空席を予約し、着席後に注文を開始する構成です。移動中に客が破棄されても席が使用中のまま残らないよう、席の予約と解放をまとめて管理しました。

リトライ後のUIと振り返り画像

シーンをまたいで保持するScoreManagerには、新しいシーンのUIをつなぎ直す処理を追加しました。振り返り画像は保存枚数を制限し、使い終えたTexture2DはClear()だけでなくDestroy()で解放しています。

手の震え体験ゲーム

実物のカップ型デバイスを持ち、水をこぼさずに家の中のゴールを目指すゲームです。手の揺れや不安定さで、日常の動作が難しくなる感覚を体験してもらうことを目的に開発しています。

右手でカップ、左手でキーボードを操作します。ランダムに傾くゲーム内のカップを、実物デバイスを動かして補正します。水がなくなるとゲームオーバーになります。

Unity / C# / ATOM Matrix / IMU / Wi-Fi・UDP

研究テーマ：
コップ型デバイスを用いた手の震え体験ゲームの開発

実装を進めた内容

  • IMUの値をUnity内のカップ操作に反映
  • 外乱による傾きと、プレイヤーの補正判定
  • 水の揺れ・こぼれとWaterゲージの減少
  • IMU確認・キャリブレーションからClear / Game Overまでの進行
  • 振動動作と、室内のギミック

プレイ動画

カップ型デバイスと振動

ATOM MatrixのIMUでカップの動きを取得し、Wi-Fi経由のUDP通信でUnityへ送信します。Unity側からは振動命令を送り、手元へのフィードバックにつなげます。

  • 右手：実物のカップを傾けて補正
  • 左手：キーボードで移動

大きな傾きを振動でも伝えるため、強さとタイミングを調整しています。動画では、実物デバイスの振動動作を確認できます。
